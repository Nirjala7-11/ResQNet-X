# 🚨 ResQNet-X  
### AI-Powered 5G Edge Intelligence for Real-Time Survivor Detection & Rescue Optimization  

---

## 🌍 Overview

ResQNet-X is an AI-driven disaster response platform designed to enable **real-time survivor detection, risk analysis, and rescue prioritization** using simulated 5G edge intelligence.

> “We don’t just detect disasters — we decide who to save first.”

---

## ⚠️ Problem

During disasters:
- No real-time decision support  
- Manual and slow rescue operations  
- Lack of prioritization  

---

## 💡 Solution

ResQNet-X provides:
- 🧠 AI-based survivor detection  
- ⚠️ Risk analysis engine  
- 📊 Priority scoring system  
- 🎯 Decision recommendations  
- 🌍 Live dashboard (Digital Twin view)  

---

## 🏗️ System Architecture
Data Sources → 5G Layer → Edge AI → Priority Engine → Decision Engine → Dashboard


---

## ⚙️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS

**Backend:**
- FastAPI / Node.js

**AI/ML:**
- OpenCV
- YOLO (for detection)

**Real-Time:**
- WebSockets

---

## 📡 Role of 5G

- URLLC → Real-time alerts  
- eMBB → Video streaming  
- mMTC → Large-scale device data  
- MEC → Edge AI processing  

---

## 🎥 Demo Flow

1. Disaster occurs  
2. Data is generated  
3. AI detects survivors  
4. Priority is calculated  
5. System suggests rescue actions
